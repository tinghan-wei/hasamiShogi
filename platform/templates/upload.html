{# ── Protocol reference ──────────────────────────────────────────────── #}

  1. Read one line: OK? → print your player name, flush.
  2. Read one line: Black or White.
    • If Black: immediately print your first move (4 digits, e.g. 0102) and flush.
    • If White: wait for step 3.
  3. Loop:
    • Read one line: the opponent's last move (4 digits) or GAME_OVER WIN/LOSS/DRAW.
    • If GAME_OVER: exit.
    • Otherwise: apply the move to your internal board, choose your move, print it, flush.

Move format: r1c1r2c2 (row/col of piece to move, row/col of destination). Rows and columns are 0–8.

See randomPlayer.py in the repository for a minimal working example.

Standard library modules that are safe to use:

hasamiShogi, sys, random, copy, math, collections, heapq, itertools, functools, typing, abc, time, re, json

Network access (socket, urllib, …), file I/O (open, os, pathlib, …), subprocesses, dynamic code (exec, eval), and ctypes are blocked and will cause your upload to be rejected. Players run in an isolated Docker container with no network and a read-only filesystem.
